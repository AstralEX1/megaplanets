# Delivery Roadmap

Each stage ends with a user-visible checkpoint. Work must not continue into the next
stage until the user explicitly requests it.

## Stage 1 — Repository foundation

Import the starter kit, install project guidance and the Megapot skill, configure Base
documentation access, create subsystem boundaries, and verify the clean build.

## Stage 2 — One-ticket Megapot purchase

Target Base Sepolia, support manual and quick-pick selection, exact approval, source
and referrer attribution, receipt decoding, and persisted ticket ID confirmation.

## Stage 3 — Deterministic planet generator

Adapt the user-owned generator, add versioned seed and weighted palette configuration,
produce GIF previews, calculate points and rarity, and lock golden outputs in tests.

## Stage 4 — Planet NFT contract

Implement and test the non-upgradeable ERC-721, EIP-712 voucher verification, live
ticket ownership checks, burned-ticket authorization, and immutable token metadata.

## Stage 5 — Metadata and eligibility backend

Index eligible ticket events, resolve ownership, generate and pin canonical metadata,
and issue replay-protected mint vouchers.

## Stage 6 — Base Sepolia Planet mint

Deploy and verify the contract, connect the voucher and mint UI, and complete a real
eligible ticket-to-Planet transaction.

## Stage 7 — Product pages and leaderboard

Finish the Planet gallery and history surfaces, daily ownership snapshots, weekly
score aggregation, and proportional reward allocation display.

## Stage 8 — Public MVP release

Deploy Vercel and Supabase infrastructure, publish the repository, run browser smoke
tests, and prepare the public demo and submission documentation.
