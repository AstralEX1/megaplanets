# Play Expedition UI

## Goal

Replace the existing Play configurator presentation with the approved Paper
expedition layout while preserving all current Megapot purchase, approval,
bulk-order, and post-purchase reveal behavior.

## Layout and responsive behavior

- The desktop experience centers the expedition control column. It shows the
  current drawing state, three unrevealed planet silhouettes, a quantity slider,
  and the primary explore button.
- Quantity has one source of truth. The slider supports values 1 through 50,
  starts at 1, and labels the 1, 10, 25, and 50 landmarks. It updates the
  silhouette count, quantity label, checkout text, and exact dynamic USDC total.
- Coordinates are collapsed by default. On desktop, the adjacent arrow toggles
  a right-side coordinates panel with a CSS transition. On smaller screens the
  existing accessible disclosure/bottom-sheet interaction remains usable.
- The open panel presents manual ticket rows with live normal/bonus-ball values
  and a Shuffle control. Rows open the existing ticket picker; removal and
  adding a ticket retain their existing eligibility rules. Quick-pick tickets
  are still generated by Megapot when checkout is submitted.

## Functional boundaries

- Preserve dynamic drawing ID, sales phase, ball bounds, ticket price,
  exact-amount USDC approval, direct purchase, and bulk purchase routing.
- Do not expose manual-coordinate controls beyond the existing
  `MAX_CUSTOM_TICKETS` limit. Quantity remains capped at 50 in the new UI, so
  the bulk route is unchanged but not selected through this initial screen.
- The Explore button continues to open the confirmation dialog before any
  wallet transaction. A successful purchase continues to show the existing
  discovered-planets and mint/reveal flow.

## Target cursor

- Add React Bits TargetCursor as a desktop-only, global decorative component.
- Add `cursor-target` to buttons, slider, ticket rows, and the coordinates
  toggle. Touch devices retain native behavior and no custom cursor is rendered.
- Install the required `gsap` package with pnpm. Keep the cursor fixed,
  pointer-events-free, and outside transformed containers so it cannot block
  interaction or alter transaction behavior.
- Respect reduced-motion preferences by disabling the spinning custom cursor.
